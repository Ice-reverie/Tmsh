# 基于FastCAE平台的面向仿真的网格生成软件Tmsh

**Tmsh**是开源工业软件实战集成赛参赛作品，是依据比赛需求基于FastCAE平台开发并集成了相关功能模块的软件，为CAE仿真分析提供从CAD模型到高质量计算网格的一站式解决方案。支持大型模型处理。

##  核心特性

###  Detri2 - 曲面三角网格生成

- **全格式兼容**：支持主流CAD格式 **STEP、IGES、STL**，兼容工业标准
- **智能自适应加密**：曲率驱动自动细化（曲率半径<1mm区域自动加密）
- **尺寸场自定义**：基于邻近度、曲率或用户定义函数精准调控局部密度
- **质量优化**：内置网格优化算法，确保最小角>25°，避免几何失真

###  TenGen - 四面体网格生成

- **TetGen算法继承**：Delaunay优化生成，保障单元质量（最大体积比<3）
- **稳健性处理**：完美支持多孔介质、薄壁结构（厚度<0.1mm）
- **局部自适应加密**：基于求解器反馈或用户标记，关键区域密度提升2-4倍
- **自动重剖分**：可以设定阈值（如最小二面角≥10°），自动优化未达标区域
